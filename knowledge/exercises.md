# Exercise knowledge base

This file is read by the coach's specialist agents (program design, logging,
substitution suggestions, weekly-volume counting). It is the full eleven-column
exercise table and is the source of truth from which the user-facing five-column
table (`templates/{ru,en}/exercises.md`, generated by
`scripts/dev/build-exercise-tables.mjs`) is derived. Do not hand-edit the
generated tables — edit this file and re-run the generator.

Copied faithfully, without paraphrasing, from the project's research notes on the exercise database
(sections 1-9: purpose, naming conventions, controlled vocabularies, the "Main"
lift criterion, load type, the 157-row exercise database, the fractional volume
credit table, substitution groups, and alias-resolution notes). See that report
for full source citations and licensing.

## 1. Purpose & how the coach reads this table

This file is both documentation and a parser input. The coach resolves a dictated or typed exercise name (EN or RU, canonical or alias) to one row, then uses `Primary muscle` / `Secondary muscles` to credit weekly volume (see §7 for fractional credit on compound lifts), `Main` to decide whether RPE is required and whether the exercise gets long-term e1RM/tonnage trend tracking, `Load type` to decide how to compute e1RM (external load formulas vs. bodyweight-adjusted formulas), and `Substitutes` to suggest a same-pattern alternative when a station is busy.

The main table (§6) is split into 18 sub-tables grouped by movement pattern for readability. Every sub-table uses the identical 11-column header in the identical order:

`Exercise EN | Exercise RU | Aliases EN | Aliases RU | Equipment | Pattern | Primary muscle | Secondary muscles | Main | Load type | Substitutes`

A `—` in `Secondary muscles` means the movement is effectively single-muscle isolation with no meaningfully loaded synergist worth volume-crediting.

## 2. Naming conventions

**a. Canonical EN name.** Title Case, no equipment prefix unless a same-named barbell version exists and needs disambiguation (e.g. `Bench Press` stays bare because it's the barbell default; the dumbbell/machine/Smith versions get an explicit equipment prefix: `Dumbbell Bench Press`, `Machine Chest Press`, `Smith Machine Bench Press`).

**b. Canonical RU name.** Uses the most common *written* (not slangy) full form as seen on Russian fitness reference sites (sportwiki, iron-health) — e.g. `Становая тяга (классическая)`, not `стан`. Short/colloquial/abbreviated forms live in `Aliases RU`, never in the canonical column.

**c. Grip/stance variations — alias vs. separate row.** Rule: a grip or stance change is an **alias/note on the same row** when it does not change the `Primary muscle` assignment and is not conventionally tracked as its own PR history (e.g. shoulder-width vs. wide-stance back squat; standing vs. seated dumbbell curl; palms-forward vs. neutral shrug). It becomes a **separate row** when it shifts the primary muscle or is conventionally programmed/tracked as a distinct lift (sumo vs. conventional deadlift, close-grip vs. flat bench press, chin-up vs. pull-up, front vs. back squat). This keeps the table from exploding combinatorially while still letting the coach track what lifters actually treat as different exercises.

**d. Pause / deficit / pin / tempo variants.** Pause, deficit, and pin variants of the three powerlifting main lifts (squat, bench, deadlift) get **their own row**, because they're commonly programmed and PR-tracked separately (`Pause Squat`, `Pin Squat`, `Pause Bench Press`, `Pin Press (Bench)`, `Deficit Deadlift`). Generic **tempo** prescriptions (e.g. "3-1-1 tempo bench press") do **not** get a separate row — tempo is logged as a per-set note/tag on the base exercise, since almost any exercise can carry a tempo prescription and a row per tempo combination is unmanageable. The same restraint applies to non-powerlifting accessories: no `Pause Leg Press` row, for example, unless a specific variant becomes common enough to warrant its own tracked history.

**e. Machine naming.** `machine:<name>` uses a short lowercase-hyphen slug from the equipment vocabulary (§3.1). The same slug is reused across gym brands (e.g. every pin-stack pec-deck-style machine is `machine:pec-deck`), since the coach can't know brand-specific load calibration anyway and shouldn't pretend to.

## 3. Controlled vocabularies

### 3.1 Equipment

`barbell` · `dumbbell` · `ez-bar` · `trap-bar` · `cable` · `smith` · `bodyweight` · `band` · `kettlebell` · `bench` (accessory, combined with barbell/dumbbell/bodyweight) · `rack` (accessory, for box/pin/rack-pull work) · `pull-up-bar` · `dip-station` · `landmine` · and `machine:<name>` for fixed-path selectorized equipment, specifically: `machine:leg-press`, `machine:hack-squat`, `machine:leg-extension`, `machine:leg-curl`, `machine:pec-deck`, `machine:chest-press`, `machine:shoulder-press`, `machine:lateral-raise`, `machine:t-bar-row`, `machine:chest-supported-row`, `machine:seated-row`, `machine:pullover`, `machine:assisted-pullup`, `machine:assisted-dip`, `machine:hip-abduction`, `machine:hip-adduction`, `machine:glute-kickback`, `machine:hip-thrust`, `machine:back-extension`, `machine:reverse-hyper`, `machine:ghd`, `machine:ab-crunch`, `machine:captains-chair`, `machine:standing-calf-raise`, `machine:seated-calf-raise`.

Rule of thumb used throughout the table: **`cable`** = adjustable pulley + weight stack where the user picks the handle/attachment (pulldown, row, fly, pushdown, face pull, curl, kickback, woodchopper, Pallof press). **`machine:<name>`** = a fixed-path selectorized unit with one movement only (leg press, hack squat, leg curl, leg extension, pec deck, chest/shoulder press machine, seated row machine, assisted pull-up/dip, hip abduction/adduction, calf raise, glute kickback, T-bar row, reverse hyper, GHD, ab crunch machine).

### 3.2 Movement pattern

`squat` · `hinge` · `horizontal push` · `vertical push` · `horizontal pull` · `vertical pull` · `lunge` · `carry` · `core` · `isolation:<muscle>` (isolation tag uses the exact muscle token from §3.3, e.g. `isolation:biceps`, `isolation:calves`).

### 3.3 Muscle groups (14, fixed list)

`chest` · `back-lats` · `back-upper` (traps/rhomboids/mid-back) · `lower-back` (erectors) · `shoulders-front` · `shoulders-side` · `shoulders-rear` · `biceps` · `triceps` · `forearms` · `quads` · `hamstrings` · `glutes` · `calves` · `abs`.

**Known gap:** this fixed list has no dedicated **adductors** group. Hip-adduction-dominant work (`Hip Adduction Machine`, and secondarily `Cossack Squat`, `Sumo Deadlift`) is credited to `glutes` as the nearest available group — this is a deliberate approximation, flagged wherever it applies, not a claim that adductors and glutes are the same muscle.

## 4. "Main" lift criterion

`Main: yes` is reserved for **heavy, multi-joint, barbell- or trap-bar-loaded compound lifts** that function as primary strength indicators in most strength/powerbuilding programs — where RPE should be logged on every working set and e1RM/tonnage should be tracked as a long-term trend. This deliberately **excludes** dumbbell, machine, cable, and Smith-machine versions of the same movement pattern (even a heavy dumbbell bench press or dumbbell RDL is `Main: no`), because those aren't standardized/comparable loads across equipment the way a free barbell or trap-bar lift is, and they're rarely what a lifter means when they say "my bench went up." It **includes** bodyweight+ lifts that are conventionally PR-tracked the same way (weighted pull-up, weighted dip), and the pause/deficit/pin main-lift variants per §2d.

The 33 `Main: yes` rows in the original research pass: the squat family (`Back Squat`, `Front Squat`, `Box Squat`, `Safety Bar Squat`, `Pause Squat`, `Pin Squat`, `Zercher Squat`), the deadlift/hinge family (`Conventional Deadlift`, `Sumo Deadlift`, `Romanian Deadlift`, `Stiff-Leg Deadlift`, `Trap Bar Deadlift`, `Deficit Deadlift`, `Rack Pull`, `Good Morning`, `Hip Thrust`, `Power Clean`), the bench family (`Bench Press`, `Incline Bench Press`, `Decline Bench Press`, `Close-Grip Bench Press`, `Floor Press`, `Pause Bench Press`, `Pin Press (Bench)`), the press family (`Overhead Press`, `Push Press`, `Seated Overhead Press`), the row family (`Bent-Over Row`, `Pendlay Row`), the bodyweight+ family (`Dip`, `Weighted Dip`, `Pull-Up`, `Chin-Up`). This borderline-call set (e.g. including `Floor Press` and `Good Morning`, excluding `Kettlebell Swing` and `Trap Bar Deadlift`'s dumbbell-adjacent cousins) is expert judgement, not a bright-line rule from any single source — a coach implementation should let a user override the flag per-exercise.

**Post-research addition:** `Pause Deadlift` was added after the original research pass (a gap found while reviewing `agents/program-strength.md`, which prescribes it) — bringing the current table to 34 `Main: yes` rows. It follows §2d's rule that pause/deficit/pin variants of the three powerlifting main lifts get their own row, mirroring `Pause Squat` and `Pause Bench Press`.

## 5. Load type

`external` — the tracked weight is the load added to a bar/dumbbell/machine stack; standard e1RM formulas (Epley/Brzycki/etc.) apply directly. `bodyweight` — no added load at all (push-up, pull-up unweighted, bodyweight lunge); e1RM needs a bodyweight-relative table or is simply not computed. `bodyweight+` — bodyweight exercise that is commonly done weighted (added plate/belt) **or** assisted (band/machine); e1RM/tonnage must add or subtract the assistance/added load from bodyweight, and the coach must know the lifter's bodyweight to compute it at all. This distinction matters directly for volume/tonnage math and is why it's a separate column from `Main`.

## 7. Fractional volume credit table (main compound lifts)

Grounded in Pelland et al.'s **fractional** volume-quantification method (meta-regression of ~67 studies / 2,058 subjects): a set where a muscle is the direct prime mover counts as **1.0**, a set where it's an indirect synergist counts as **0.5** — this binary split is what the meta-regression itself tested and found to correlate better with hypertrophy outcomes than counting every set as a full "1.0" for every muscle involved (the "total" method). The paper's own worked example: 5 sets squat + 5 sets squat + 5 sets leg press in a week is 15 "total" sets but 12.5 "fractional" sets for quads if leg press is scored as an indirect contributor in that context.

**Everything below the 1.0/0.5 split, and the introduction of a 0.25 tier, is this document's own expert-judgement extension** — a finer per-exercise breakdown needed for a coaching app, loosely following Renaissance Periodization's publicly described convention for secondary movers (their own stated example: bench press = chest 1.0 / front delt 0.5 / triceps 0.5; row = lats 1.0 / rear delt 0.5 / biceps 0.5). RP's convention itself is an internal coaching heuristic, not a peer-reviewed instrument — treat every row below as "reasonable starting default," not ground truth, and let users override it per exercise if their own recovery/growth response disagrees.

| Exercise | Muscle credits | Basis / note |
|---|---|---|
| Back Squat | quads 1.0, glutes 0.5, hamstrings 0.25, lower-back 0.25 | Pelland-style direct/indirect split; the 0.25 lower-back credit is expert judgement (isometric stabilizer, not a primary driver) |
| Front Squat | quads 1.0, glutes 0.5, abs 0.25 | as above; more upright torso reduces lower-back credit vs. back squat — expert judgement |
| Conventional Deadlift | hamstrings 1.0, glutes 0.5, lower-back 0.5, quads 0.25, back-lats 0.25, forearms 0.25 | RP-style differentiated credit; back-lats/forearms are isometric grip/lat stabilizers — expert judgement |
| Sumo Deadlift | glutes 1.0, quads 0.5, hamstrings 0.5, lower-back 0.25 | EMG literature (Escamilla et al.) shows higher quad and lower erector-spinae activation vs. conventional; exact split is expert-adjusted |
| Romanian Deadlift | hamstrings 1.0, glutes 0.5, lower-back 0.25 | direct hip-hinge mover; consistent with RP guidance |
| Trap Bar Deadlift | quads 1.0, glutes 0.5, hamstrings 0.5, lower-back 0.25 | more upright/knee-dominant than conventional (Swinton et al. 2011); exact split is expert judgement |
| Hip Thrust | glutes 1.0, hamstrings 0.5 | RP guidance; minimal lower-back involvement given torso is bench-supported |
| Good Morning | hamstrings 1.0, lower-back 0.5, glutes 0.5 | expert judgement — closer to RDL but with a larger lower-back moment arm |

## 9. Alias resolution notes (ambiguous terms)

- **"тяга" (bare, no qualifier)** — could mean deadlift, any row, lat pulldown, or cable pull-through. Never silently guess: ask ("какая тяга — становая, тяга в наклоне, тяга блока?"). If forced to default: on a back/pull-day session, default to a horizontal row (most common colloquial meaning in that context); on a leg/posterior-chain session, default to whichever deadlift variant the active program calls for. Always surface the resolved guess for one-tap confirmation.
- **"жим" (bare) / "press" (bare, EN)** — could mean bench press, overhead press, leg press, or any machine press. If another word qualifies it (e.g. "жим ногами"), it's unambiguous. Bare "жим"/"press" with no other context defaults to **bench press** (statistically the most common bare usage in both languages) but the coach must still ask if the day's session already logged a different press.
- **"разводка"** — ambiguous between dumbbell chest fly (`Dumbbell Fly`) and lateral raise (`Lateral Raise`). If followed by "в стороны"/"на плечи" → lateral raise. If followed by "лёжа"/"на грудь", or bare in a chest-day context → `Dumbbell Fly`. Default fallback (no other signal): `Dumbbell Fly`.
- **"икры"** — this is the *muscle group* name (calves), not a specific exercise. When dictated alone ("сделал икры 4 подхода"), ask which calf exercise, or default to `Standing Calf Raise (Machine)` if that equipment is in the user's known gym profile.
- **"пресс"** — muscle group name (abs), not one exercise. Same handling as "икры": ask, or default to `Crunch` / `Cable Crunch` depending on the program's typical ab exercise for that user.
- **"бабочка"** — ambiguous between `Pec Deck` (chest) and `Reverse Pec Deck` (rear delt), since most pec-deck machines have both settings. Default = `Pec Deck` unless "обратная"/"задняя"/"на плечи" qualifies it.
- **Unambiguous slang** (resolve directly, no disambiguation needed): "молотки" → `Hammer Curl`; "франц" (bare) → `Skull Crusher`, "франц стоя" → `Standing EZ-Bar French Press`; "гакк" → `Hack Squat`; "румынка" (bare) → `Romanian Deadlift`, "румынка с гантелями" → `Dumbbell Romanian Deadlift`; "жим узким" → `Close-Grip Bench Press`; "тяга гориз" → `Seated Cable Row`.
